# app-collection 仓库

该仓库为所有小型应用的集合。他们大多是**预编译的**，你可以直接将目录中 `.hpappdir` 文件传输至 Prime 运行。每个小型应用都有 `README.md` 说明其功能与用途，我们也在下面为你提供了基于类别的索引和简要描述。**如果你尚未贡献过，这个仓库是首次提交的绝佳选择**。

`/examples` 文件夹提供一些为示范用法而提供的程序，所以它们不一定那么实用，但它们的源码是你实践时的最优参考资料！

## 目录

### 游戏
[`examples/suika-prime`](https://github.com/nbprime-team/app-collection/blob/main/examples/suika-prime/) - 一个简单的消除水果游戏，相邻相同水果合并成更大水果。该示例旨在展示触摸事件处理、图形绘制以及 ASCII 字符绘制。
